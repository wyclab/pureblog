# 2026-08-01

## 修复 wyclab.com 搜索功能无法构建的问题

**症状**: 线上 wyclab.com `/pagefind/` 返回 404,搜索功能失效。

**根因** (两处都在 `src/site.config.ts`,均由最近一次提交 73d62ed "Update site.config.ts" 引入):
1. 注释掉 `quote` 配置时留下了一个悬空的 `},`(原来 quote 块结束的闭合括号),导致 `integ` 对象被提前闭合,后续 `typography`/`mediumZoom`/`waline` 配置错位,esbuild 报 `Expected identifier but found "}"`,构建在配置解析阶段就崩溃,pagefind 索引永远不会生成。
2. `quote` 是 astro-pure 1.4.6 `IntegrationConfigSchema` 中的**必填字段**(z.object 无 optional),整体注释掉后校验失败报 `integ.quote: Required`。

**修复**:
- 删除多余的 `},`,恢复 quote 配置为启用状态(server: 'https://v1.hitokoto.cn/?c=i', target 取 data.hitokoto)。
- 本地构建验证通过:pagefind 索引 124 页、11675 词、146 个文件,产物在 `dist/client/pagefind/`。

**注意**:
- 本机 WorkBuddy 沙箱会通过 NODE_OPTIONS 注入 genie-safe-delete shim,拦截 astro 构建清理 `.vite`/`.prerender` 临时目录,本地构建需用 `NODE_OPTIONS="--use-system-ca" npx astro build` 绕过(仅本地验证用,云端 EdgeOne 无此问题)。
- EdgeOne Pages 输出目录需指向 `dist/client`(astro 6 + @edgeone/astro 静态产物在 dist/client 而非 dist)。
- 线上部署的 GitHub 链接还是旧值 `wuyucun/pureblog`,当前配置已是 `wyclab/pureblog`,说明线上仍是修复前的旧产物,重新部署后即更新。
